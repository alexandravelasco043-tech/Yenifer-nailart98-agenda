INSTALACIÓN EN GITHUB PAGES
1. Extrae este ZIP en tu celular o computador.
2. Sube TODOS los archivos que están dentro (no subas el ZIP) a la raíz del repositorio.
3. En GitHub entra a Settings > Pages.
4. En Build and deployment selecciona Deploy from a branch.
5. Branch: main. Folder: /(root). Pulsa Save.
6. Espera a que GitHub Pages publique el sitio y abre la dirección del repositorio.

La aplicación guarda la información en el dispositivo/navegador (localStorage). Exporta una copia JSON desde Respaldo con frecuencia. Para restaurarla, selecciona ese JSON desde Respaldo.
Los precios iniciales del catálogo están en cero: edítalos en Servicios y extras.
